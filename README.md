# Alzikrayat | Memories Platform

## Description
A simple photo-sharing web platform where users can upload, view, and comment on their personal photos.
Built entirely with pure PHP (no framework), following the MVC pattern.

## Technologies
- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Bootstrap 5

## How to Run
1. Place the `alzikrayat` folder inside your local server directory (`C:/xampp/htdocs/alzikrayat`).
2. Open `http://localhost/phpmyadmin`, create a database named `alzikrayat`, and import `alzikrayat.sql`.
3. Start Apache and MySQL from XAMPP/WAMP.
4. Open your browser and go to: `http://localhost/alzikrayat/public/`
